# Self-Hosted Large Language Model Chatbot

This project implements a chatbot using a self-hosted large language model. The user interface is built with Streamlit, providing an interactive and user-friendly experience.

## Features

- **Self-Hosted LLM**: Utilizes a locally deployed large language model for enhanced privacy and customization.
- **Streamlit Interface**: Offers a clean and intuitive web-based interface for easy interaction with the chatbot.
- **Real-time Responses**: Generates responses on-the-fly, allowing for dynamic conversations.
- **Contextual Awareness**: Uses chat history as context for more coherent and relevant responses.
- **Customizable**: Easily adaptable to different use cases and domains.

## Getting Started

1. Clone this repository
2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   streamlit run app.py
   ```

## Usage

After starting the application, navigate to the provided local URL in your web browser. You can then interact with the chatbot by typing messages in the input field and receiving responses from the model.
